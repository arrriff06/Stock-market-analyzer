# 📈 Stock Market Analyzer

A web-based Stock Market Analyzer that allows users to search for popular stock symbols, retrieve daily stock market data, and visualize stock price movements through interactive charts and analytical insights.

The application uses the Alpha Vantage API to fetch stock market information and Chart.js to display data in an interactive and user-friendly interface.

## 🚀 Features

- **Stock Search:** Search for stocks using their ticker symbols.
- **Popular Stocks:** Quick access to popular stocks such as AAPL, MSFT, GOOGL, TSLA, and AMZN.
- **Live API Integration:** Fetch daily stock market data using the Alpha Vantage API.
- **Interactive Charts:** Visualize stock price movements using Chart.js.
- **Stock Analysis:** Display useful stock information through analysis cards.
- **Loading Indicators:** Show loading states while fetching stock data.
- **Error Handling:** Display appropriate messages when invalid symbols or API errors occur.
- **Local Storage:** Store selected information in the browser using LocalStorage.
- **Responsive Design:** User-friendly interface for different screen sizes.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Application logic and API integration |
| Alpha Vantage API | Stock market data |
| Chart.js | Interactive stock charts |
| Fetch API | Retrieving data from the API |
| LocalStorage | Client-side data storage |
